### 整体流程梳理
选择语言 → 进入模型配置面板
两种模式：**自动检索匹配模型** / **手动指定模型**
支持**同时绑定多个模型**（同一个语言可以挂多个模型，可轮询、可对比结果）

### UI逻辑（tkinter）
1. 下拉框选语言（上面LANG列表），选中后触发回调
2. 区域分两块：
    - ✅【自动搜索模型】按钮：根据语言编码（fr/ru/es/ar/de）去模型库/魔搭API检索支持该语种的模型，下拉列出候选
    - ✅【手动添加模型】输入框：直接填模型ID、API地址、token，自由录入
3. 模型列表容器（Listbox / Treeview）：**支持多条**，同一个语种可以添加多个模型
    - 每条条目显示：模型名称 + 类型（自动检索/手动录入）
    - 附带操作：删除、上移下移、启用/禁用勾选框
4. 执行策略（给Agent）
    - 多模型模式：支持二选一
      - 轮询：依次调用不同模型翻译
      - 并行对比：全部调用，输出多个翻译结果对照
5. 阿拉伯语特殊处理：
    - 检测编码 `ar`，文本控件开启 `justify=tk.RIGHT` RTL渲染
    - 提示：缺少阿拉伯字体时弹窗提醒安装字体包

### 核心回调伪代码示意
```python
def on_select_lang(event):
    selected_lang_code = lang_combo.get()
    # 清空当前模型候选区
    model_candidate_list.delete(0, tk.END)

def auto_search_model():
    code = lang_combo.get()
    # 请求模型检索接口，筛选支持该语种的模型
    result_list = fetch_model_by_lang(code)
    for m in result_list:
        model_candidate_list.insert(tk.END, m["name"])

def add_selected_model():
    # 把选中的候选模型加入【已绑定模型列表】，允许多个
    sel = model_candidate_list.curselection()
    for idx in sel:
        item = model_candidate_list.get(idx)
        bound_model_list.insert(tk.END, item)

def add_manual_model():
    mid = manual_model_input.get().strip()
    if mid:
        bound_model_list.insert(tk.END, f"【手动】{mid}")
```
