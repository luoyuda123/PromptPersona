# 多语言多模型智能画像生成系统项目方案
## 一、项目概述
### 1.1 项目背景
现有 PromptPersona 用户画像生成工具，具备**12维度用户偏好问卷 + 自动生成系统提示词 + 本地配置持久化**能力。

原有局限：
1. 语言数量有限，不支持全球主流通用语种
2. 仅单模型运行，无法自由切换、对比、轮询多模型
3. 无模型检索、手动添加、多模型管理体系
4. 无语种与模型绑定机制，无法实现**语种专属模型调度**

为满足**全球化多语言界面 + 多AI模型自由挂载 + 自动匹配语种模型 + 多模型并发/轮询运行**需求，启动本升级项目。

### 1.2 项目目标
1. 支持**全球10大主流通用语言**界面切换（含阿拉伯语RTL从右到左排版）
2. 实现「选语言 → 匹配专属AI模型」完整业务流程
3. 支持**自动搜索模型、手动添加模型、多模型同时挂载**
4. 支持多模型轮询、多模型结果对比、模型启用/禁用
5. 完全本地轻量化、免部署、一键打包、配置永久留存
6. Agent 读取标签统一为中文，不受界面语言影响，保证调度稳定

## 二、核心功能需求
### 2.1 多语言国际化系统（10国语言）
支持语言列表：
1. 简体中文（zh）
2. 繁体中文（zh-tw）
3. 英语（en）
4. 日语（ja）
5. 韩语（ko）
6. 法语（fr）
7. 俄语（ru）
8. 西班牙语（es）
9. 德语（de）
10. 阿拉伯语（ar，RTL从右至左排版）

功能特性：
- 首次打开自动弹出语言选择器
- 选择语言后永久保存配置，下次自动载入
- **后台Agent标签全部中文固化**，界面多国语言分离解耦
- 阿拉伯语自动适配RTL右对齐布局，兼容Windows系统字体修复提示

### 2.2 多模型智能调度核心（新增核心模块）
#### 2.2.1 业务流程
**启动软件 → 选择界面语言 → 自动检索适配该语种的AI模型 / 手动添加模型 → 挂载多模型 → 生成画像并多模型执行**

#### 2.2.2 两种模型接入模式
1. **自动搜索模型（智能匹配）**
   - 根据当前选中语言编码，自动检索适配该语种的大模型
   - 下拉展示可用模型列表（翻译/对话/生成类模型优先）
   - 一键添加至「已挂载模型列表」

2. **手动添加模型（自由拓展）**
   - 支持手动输入：模型ID、API地址、Token、本地模型路径
   - 不限模型数量、不限模型厂商、不限开源/闭源

#### 2.2.3 多模型管理能力
- 支持**同时挂载 N 个模型**
- 单个语种可绑定多个专属模型
- 模型启用 / 禁用 独立开关
- 模型上移、下移排序（自定义执行优先级）
- 单模型删除、批量清空

#### 2.2.4 多模型运行策略
1. **轮询模式**：每次对话自动切换不同模型，均衡调用
2. **并行对比模式**：所有启用模型同时输出结果，多版本对照
3. **单模型优先模式**：指定主模型，其余为备用

### 2.3 原有画像系统保留完整功能
- 12维度用户偏好问卷
- 自动生成标准化系统画像 Prompt
- 私密备注系统（可选择是否注入提示词）
- 自动生成三文件：
  - persona.json（Agent读取配置）
  - secret_note.json（私密配置）
  - persona_system.txt（可直接复制系统词）
- 配置本地持久化、不丢失

## 三、整体系统架构
### 3.1 架构分层（轻量化本地架构）
1. **UI展示层**
   - Tkinter 多语言动态渲染界面
   - RTL阿拉伯语布局引擎
   - 多模型管理面板、列表控件、开关控件

2. **语言管理层**
   - 全局 LANG 字典国际化翻译池
   - 独立 TAG_MAP 中文标签池（Agent核心调度不动）
   - 语言配置持久化 config.json

3. **模型调度层（新增）**
   - 语种-模型匹配引擎
   - 自动模型搜索接口封装
   - 多模型队列管理器
   - 多策略执行控制器（轮询/并行/优先）

4. **数据持久层**
   - 语言配置、模型列表、模型状态、用户画像全部本地JSON保存
   - 免数据库、轻量化、绿色便携

### 3.2 解耦设计（核心亮点）
- **界面语言与Agent逻辑完全分离**
- 无论用户切换任何外语，Agent识别标签永远中文
- 保证多语言不乱码、不冲突、不影响模型调用逻辑

## 四、界面结构设计
### 4.1 启动页
- 全局语言选择窗口（10国语言按钮列表）

### 4.2 主界面布局
1. 顶部：当前语言展示 + 语言重选按钮
2. 中上：12维度多语言问卷区
3. 中部：**多模型配置专区（新版核心）**
   - 自动搜索模型按钮
   - 手动模型输入框 + 添加按钮
   - 已挂载模型列表（带启用勾选、排序、删除）
   - 运行策略选择下拉框
4. 下部：私密备注区
5. 底部：上一题、下一题、生成画像按钮

## 五、技术方案
### 5.1 开发技术栈
- 开发语言：Python3
- UI框架：原生 Tkinter（兼容所有Windows，无依赖）
- 数据存储：纯JSON本地文件
- 打包方式：Pyinstaller 单文件EXE
- 编码：全局UTF-8，兼容小语种、阿拉伯文、俄文

### 5.2 关键技术点
1. **RTL双向排版适配**
   阿拉伯语自动右对齐，控件自动反转布局

2. **多语言动态热加载**
   无需重启，配置即时生效

3. **多模型队列调度算法**
   支持有序轮询、并行调用、权重优先

4. **语种模型智能匹配**
   根据lang编码自动筛选最优语种模型

### 5.3 兼容性
- 支持 Windows10 / Windows11 全版本
- 绿色单文件、无安装、无注册表
- 支持本地大模型 + API在线模型 混合挂载
